For small agents. It works.

sprint is a terminal coding agent for small local models. It keeps them on track, checks every command, and asks before it acts.

pip install git+https://github.com/Vasiniks/sprint.git

Then run sprint. Two Python files, no dependencies.

They go in circles

The same call again, the same file rewritten, the same failure twice running: sprint warns the model once, then stops the turn and tells you why.

They garble commands

Every tool call is checked, and a reply cut off halfway is never run. You approve each command and edit, or allow the ones you trust for good. Esc stops a turn at once, and nothing can keep you from quitting.

What runs without asking

Three modes; Tab switches between them, and the one you leave in is the one you come back to. Some things are put to you in every mode.

An approval you leave for 20 seconds is set aside, not run. The model carries on with the rest, and the call waits for you under /permissions.

The model can ask you things too, when only you can answer: you type the answer in the prompt, or pick one of the choices it offers. It waits a minute, then decides for itself and says what it chose.

Commands worth knowing

/model
Switch between the models you have, or pull another by name.
/think
Let the model reason first. You watch the reasoning as it is written; /showthink shows it in full.
/plan
Lets the model keep a to-do list for a big job, the way opencode's agents do. Most messages get none. The items tick off in the side panel.
/config
Every setting, on two pages. The second is the low-level one: temperature, top_p, top_k, seed and the rest, each the model's own until you set it.
/usage
Your days as a heat map with sessions, streaks and your favourite model; tokens per day and each model's share; and this session.
/theme
Thirteen themes. Each one colours the whole window, edges included.
/update
Get the newest sprint without leaving it.

Start

  1. Install Ollama. You don't need to start it; sprint does.
  2. Install sprint: pip install git+https://github.com/Vasiniks/sprint.git
  3. Run sprint in a project folder. The first time, it offers to pull magi 1.2 2B, an 826 MB download.
  4. Type a request and press Enter. Tab switches between asking first, accepting edits, and running everything.

Works on macOS and Windows. Linux is tested in CI but not yet tried by hand. The README has every command and setting.
