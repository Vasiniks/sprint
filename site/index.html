A coding agent for very small models.

sprint runs in your terminal and drives models of 0.5B to 3B parameters on your own machine, inside an 8K context. Two Python files, no dependencies.

pip install git+https://github.com/Vasiniks/sprint.git

Then run sprint. Needs Python 3.9 or newer and Ollama.

Built around what small models get wrong

They lose track of long conversations

sprint keeps room free for the reply and folds older steps into a short summary of what you asked and what was done. File changes outlast things that were only looked at.

after folding
promptsummaryconversationkept for the reply

They go in circles

The same call again, the same file rewritten, the same failure twice running: sprint warns the model once, then stops the turn and tells you why.

read notes.txt
read notes.txt
one warning
read notes.txt
stopped

They garble commands

Every tool call is checked, and a reply cut off halfway is never run. You approve each command and edit, or allow the ones you trust for good. Esc stops a turn at once.

rm -rf build?y oncea alwaysn no

Start

  1. Install Ollama. You don't need to start it; sprint does.
  2. Install sprint: pip install git+https://github.com/Vasiniks/sprint.git
  3. Run sprint in a project folder. The first time, it offers to pull Qwen 3.5 0.8B, a 737 MB download.
  4. Type a request and press Enter. Tab switches between asking first, accepting edits, and running everything.

Works on macOS. Linux and Windows are written and tested in CI but not yet tried by hand. The README has every command and setting.
